# כספית — אתר המוצר

אתר התדמית וההורדות של **כספית**, מערכת הלוואות לעמותה.
הדף חי בכתובת: https://tzur1221.github.io/kaspit-site/

## מה כאן
- `index.html` — הדף עצמו. עמוד אחד, עברית RTL, בלי שום תלות.
- `img/` — הלוגו וצילומי המסך.

## למה ריפו נפרד
קוד התוכנה פרטי (`TZUR1221/kaspit`). הריפו הזה ציבורי כי:
1. GitHub Pages בחשבון חינמי דורש ריפו ציבורי.
2. **המתקין מתפרסם כאן ב-Releases** — וזה גם מה שהתוכנה בודקת
   כשהיא מחפשת עדכון (`api.github.com/repos/TZUR1221/kaspit-site/releases/latest`).

## פרסום גרסה חדשה
```
gh release create v1.0.1 dist/כספית-התקנה.exe --title "כספית 1.0.1" --notes "מה חדש"
```
האתר והתוכנה שניהם מושכים את ה-Release האחרון אוטומטית.
